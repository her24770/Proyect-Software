# Sistema de Conexión Estudiantil UVG  
**Proyecto – Ingeniería de Software 1**
Universidad del Valle de Guatemala

---

## 📖 Descripción del Proyecto
Este proyecto consiste en el análisis, diseño y modelación de un sistema digital que permitirá a los estudiantes de la Universidad del Valle de Guatemala intercambiar materiales académicos, ofrecer tutorías y gestionar préstamos o ventas de objetos universitarios de forma organizada, segura y centralizada.
